# VISION — Eyewear Store

A responsive Lenskart-inspired demo storefront built with vanilla HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet is needed for Google Fonts and the remote Unsplash product images.

## Features
- Responsive landing page and mobile navigation
- Product catalogue, search, category filters and sorting
- Product detail dialog
- Cart with quantity updates, remove item and subtotal
- Wishlist
- LocalStorage persistence
- Demo checkout form (no real payment processing)
- Newsletter interaction

## Customize
- Edit product data and image URLs in `script.js`.
- Change colors and layout in `style.css`.
- Update brand text and page sections in `index.html`.

## Publish on GitHub Pages
Upload `index.html`, `style.css`, `script.js` and `README.md` to the root of a GitHub repository. In Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save.

## Important
This is a frontend demo, not a production commerce system. Real accounts, inventory, order storage, secure payment gateway, shipping, admin dashboard and legal policies require a backend and provider integrations. Product imagery is loaded from Unsplash URLs and should be replaced with licensed product photos before commercial use.
